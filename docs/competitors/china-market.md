# 中国市场:低代码 / 零代码 / 多维表格 / AI 应用搭建

> 调研 2026-06-24。ObjectStack 楔子见 [README](./README.md)。中国用一把不同的尺子:**私有化 / 信创 / 数据主权 / 避免巨头生态锁定**——这是英文对手吃不到的增量战场。

## 全局结论

1. **整个品类都把 AI 当"加速器",没有一家做"可治理 AI"**——没有一家提供"AI 写→人审小 diff→运行时强制权限+审计"的闭环。这是中文深度文章的核心论点。
2. **私有化/信创把竞品劈成两半**(决定攻击话术):
   - **可以正面攻"不能私有化"的**:飞书多维表格(仅数据驻留、仍过 SaaS 后端)、维格表/APITable(开源但治理付费墙)。
   - **不能攻"不能私有化"的**(它们真能私有化,改打"开放/可迁移/可治理 AI"):钉钉宜搭、得帆、织信、明道云。
3. **别乱说"它们权限是黑盒"**——明道云、简道云、得帆都有真行/字段/动作级 RBAC + 审计。真正的缝是:**AI 改了什么没有可审阅 diff**,且 **AI 在断网/信创环境直接失效(外部云 LLM)**,外加**国产数据库认证缺口**。
4. **黑帕云已倒闭**(2022 关停、删数据),不是竞品,是数据主权文章最好的开场寓言。
5. **生态归属更正**:奥哲/氚云绑阿里/钉钉(非腾讯);真拿腾讯投资的是**轻流**。

## 第一梯队

### 飞书多维表格 (Lark Base / Feishu Bitable) — 字节跳动 — High
- **是什么**:多维表格 + AI 应用搭建,活在飞书套件里的"超级 Airtable"。
- **目标用户**:SMB→中大型,偏敏捷创新团队;**信创/政企明显弱**。
- **价格/模式**:按席位订阅,免费版 + ~5 档付费,AI 用量靠积分;具体 RMB 单价页面 JS 渲染**未核实**。
- **体量/背景**:Bitable MAU **接近 1000 万**(2024.9 ~600 万→2025 年中近 1000 万);飞书整体 ~1200 万用户、2024 国内协同份额 18.9%(第三);飞书 ARR 2024 >$3 亿(+50%,仍亏)。**字节跳动**全资。
- **核心优势**:表格 UX 第一档 + 国内最强 AI Agent 故事("应用模式"无代码、数百 AI 字段、2026 多维表格 Agent 可由自然语言生成整套业务系统含权限配置)。
- **治理/AI 弱点**:**生态锁定严重**("进飞书易,出飞书难",闭源专有非开放协议);权限是飞书后台不透明配置;**AI 黑盒**——一句话生成整套系统,无可审 diff、无审批前置;**真私有化基本没有**——"数据私有化"仍需过飞书 SaaS 后端中转,非气隙,信创适配弱。
- **挖角话术**:"飞书多维表格 AI 一键生成的,是你无法逐行审阅、也带不走的黑盒系统,数据还得过字节公有云——ObjectStack 让 AI 写、人审小 diff、运行时强制权限与审计,应用核心是你能读、能私有化、能迁走的开放元数据。"
- **文章价值:High**。体量大、AI 激进、情绪点真实(易进难出、不能私有化、单生态)。

### 钉钉宜搭 (DingTalk Yida) + 钉钉 AI 搭 — 阿里巴巴 — High(框架要准)
- **是什么**:钉钉旗舰低/零代码(表单/流程/审批)叠 AI——AI 助理(2024)→ AI 表格自然语言生成(AI 钉钉 1.0, 2025.8)→ Agent OS/DEAP(AI 钉钉 1.1"木兰", 2025.12)。
- **目标用户**:最广,个人/SMB→中大型,**两强里信创/政企故事最强**。
- **价格/模式**:宜搭免费版;轻享 ¥2,988/年起;专业 ¥5,988/年起;专属按需。钉钉平台另有专业版 ~¥9,800/年、专属 ~¥10 万/年起、专有版(私有化)。
- **体量/背景**:钉钉 ~7 亿用户、DAU >1 亿、2,300 万+ 组织、付费企业 >12 万;软件订阅 ARR FY2025 上半年 >$2 亿。**宜搭已搭 >1000 万应用**;IDC 2024/2025 国内低代码第一、AI 含量最高。**阿里巴巴**全资。
- **核心优势**:分发+生态深度(7 亿用户漏斗、最成熟审批/HR 基因、国内最大低代码应用量、最成熟信创/私有化)。
- **治理/AI 弱点**:生态锁定严重(阿里/钉钉,闭源非开放协议);权限是控制台不透明配置;**AI 黑盒**(AI 表格/Agent OS 生成复杂系统,无小 diff + 审批前置 + 改动审计);**但私有化是它真本事**——专有钉 + 飞腾+麒麟 + 等保三级 + 多活,**所以"不能私有化"对钉钉无效**。
- **挖角话术**:"钉钉宜搭就算私有化,也仍是阿里生态里封闭、带不走的黑盒——你看不到 AI 生成应用的可审 diff,也拿不到可读元数据;ObjectStack 给你同样的信创私有化,但用开放协议、可读元数据、AI 写人审小 diff + 运行时权限与审计,让企业真正拥有并治理自己的 AI 应用。"
- **文章价值:High(但更难)**。流量巨大,框架必须避开"不能私有化",死磕"AI 生成应用的治理 + 开放可迁移元数据 vs 阿里锁定 + 可审 diff"。

### 明道云 (Mingdao / HAP) — 独立 — High
- **是什么**:零/低代码 APaaS(自建 CRM/OA/类 ERP)。上海万企明道,2013 创立;2019 推 on-prem。
- **目标用户**:名义 SMB+业务部门,实际偏**中大型 + 国企/央企**;**无专门信创认证产品线(缺口)**。
- **价格/模式**:SaaS 标准 ¥14,900 / 专业 ¥29,900 / 旗舰 ¥59,900(各含 30 用户,+¥300/用户/年);私有化:社区版永久免费(**前端开源**)+ 标准/专业 on-prem 按需(渠道 ~70% 收入)。
- **体量/背景**:自报 **100 万+ 注册、4,000+ 付费企业**(未审计);客户含可口可乐、复星、三大运营商、北京地铁、华夏/民生银行、迪卡侬。融资:**仅一轮披露,2021.5 近亿元,SIG**;2022 后无新融资,~130 人。
- **核心优势**:成熟**容器化 on-prem**(Docker+K8s、~80 微服务)+ 每个数据对象**自动生成开放 REST CRUD API**(OpenAPI 3.0)+ **字段级可读 RBAC** + 强工作流。
- **治理/AI 弱点**:权限其实很强很可读(表→视图→**行**→**字段**→动作级,声明式非黑盒)——**别攻这里**;真缝在 AI+信创:AI 是**自带外部云 LLM**(OpenAI 兼容,测过 DeepSeek/火山方舟)的助理功能,**无 AI 改动可审 diff/审计**;**关键信创缺口:业务数据在 MongoDB,未提国产关系库(达梦/人大金仓/OpenGauss),且未找到信创认证**;on-prem AI 需客户自拼、非开箱、断网即废。
- **挖角话术**:"你已经信任明道云做字段级权限的本地部署——但它的 MongoDB 内核没有达梦/人大金仓/信创认证,AI 也只是自带云 LLM 的外挂、改了什么没有审计。ObjectStack 给你信创认证、可自托管的内核,每次 AI 编辑都落成人审 diff、运行时强制——气隙也能治理的 AI。"
- **文章价值:High**。on-prem 信誉强但有具体信创数据库缺口 + 资本单薄 + 助理式非可治理 AI;其重治理本地部署用户正是 ObjectStack 的 ICP。

### 简道云 (Jiandaoyun) — 帆软 / Fanruan — High(纯 SMB 段 Medium)
- **是什么**:零代码应用搭建(表单/流程/仪表盘/轻 CRM 进销存)。属**帆软**(FineReport/FineBI 背后的 BI 公司)。
- **目标用户**:核心 **SMB/全民开发**(最大零代码基数),**正上探中大型**;政企/信创靠较新独享版。
- **价格/模式**:免费版(30 用户,慷慨)/ 标准 ¥5,000 起 / 企业 ¥12,000 起 / 旗舰 ¥100,000 起;**独享版**(云或 on-prem)按需、200 席起。
- **体量/背景**:简道云 ~**2,200 万注册、~180 万组织、~350 万应用**;自称 IDC 中国零代码连续四年第一(~34.5%)。母公司帆软 **2024 营收 15.7 亿(~$2.2 亿)、盈利、完全自举、明确"永不上市"**,~2,000 人。(注:3.6 万企业/财富 500 是帆软整体非简道云。)
- **核心优势**:易用 + 慷慨免费版 + 帆软 BI 基因(交叉销售 FineReport/FineBI)+ 独有**财务韧性**(盈利、零负债、品类领先母公司)。
- **治理/AI 弱点**:权限可读(三维:操作+字段+数据行级 + 权限组 + 操作日志)——**别攻这里**;真缝:私有化比明道云更新更窄,**信创缺口具体**(CPU 鲲鹏920+海光、**未列飞腾**;OS 麒麟/统信/欧拉/龙蜥 OK;**数据库仅巨杉+钛铂,无达梦/人大金仓/GBase/OceanBase**);**AI 是接外部云 LLM(阿里云通义千问)的工作流节点**,只记"跑过了"、**无 AI 输出可审 diff**,气隙信创基本失效。
- **挖角话术**:"简道云的 AI 就是把通义千问云 API 接进工作流节点——它记录自己跑过,却从不给你它改了什么的可审 diff,更进不了气隙信创(无达梦/人大金仓、无飞腾)。ObjectStack 反着造:信创认证、可自托管内核 + 开放可读元数据 + 每次 AI 改动渲染成人审小 diff、运行时强制——拔了网线也能治理。"
- **文章价值:High(纯 SMB 段 Medium)**。2,200 万用户=高触达;**别质疑帆软稳定性**(它最稳),死磕上探/信创/可治理 AI。

## 第二梯队

### 腾讯微搭 (Tencent WeDa) — 腾讯 — High
- 腾讯云官方企业低代码(Web/H5/小程序),基于 CloudBase。目标:中大型+政企。价格 ~¥5,388/开发者/年;私有化版首年促销 ~¥2,388/年。深绑**企业微信+腾讯云**;政企案例含国务院客户端、北京协和、工行。弱点:生态锁定重(只在企微+腾讯云最大化)、AI 是布局/组件生成助手非可治理管线、逻辑专有非开放协议、私有化仍在腾讯封闭栈内。
- **挖角**:"微搭让你成为腾讯生态的租户——应用、数据、身份都假设企微+腾讯云;ObjectStack 给你同样的 AI 搭建速度,但化作你完全拥有、可审计、可自托管的开放元数据,无单厂商云依赖、无信创/数据主权风险。"
- **文章价值:High**——名气最大,"生态锁定 vs 开放可治理"叙事干净。

### 轻流 (Qingflow) — 上海奥畅(腾讯系) — High
- AI 无代码"表单+流程"平台(已改口"AI 无代码系统搭建")。目标:SMB→中端→企业。价格(透明):免费/团队 ¥9,600/年(50 用户)/专业 ¥15,600/年/企业智能版 ¥19,600/年(含"轻翼"AI);专有轻流(私有化)按需。**20 万+ 企业;腾讯投资确认入股**(~6 轮:启明、零一、**腾讯投资**、源码等)——**真拿腾讯钱的是它,不是奥哲**。弱点:腾讯生态集成(HiFlow 连接器)=生态锁定;AI 是"轻翼/Q-Robot"生成,治理仍是传统角色权限+数据脱敏开关,**AI 输出与运行时之间无人审 diff 闸门**;闭源专有 SaaS、非开放协议;自托管存在但定制/付费、架在云优先封闭平台上。
- **挖角**:"轻流在腾讯背书的云表单上加了 AI——AI 直接'做事',你只能信它。ObjectStack 反过来:AI 写、人审可读小 diff、运行时强制对象/记录/字段/动作权限+审批+审计——开放元数据上可治理的 AI、你自托管。"
- **文章价值:High**——最强的在位 AI 无代码竞品(有规模、有钱、有真 AI 故事)。

### 得帆 / 得帆云 Definesys — 上海得帆(百度风投系) — High
- 企业低代码 PaaS 套件:DeCode(aPaaS)+DeFusion(iPaaS)+DeMDM(主数据)+DeHoop(数据中台)。2014 创立(起家 Oracle 中间件)。目标:中大型/集团(中国前十车企占 8 家)。价格:有公开 SaaS 档(团队 ¥6,800/标准 ¥12,800/高级 ¥19,800/年)+ 不标价企业版 + 私有化版。融资:2021 A 轮百度风投领投、2022.9 A+ 5,000 万元。Gartner 2023–2024 入选中国 ICT 成熟度曲线。
- **优势**:**集成+主数据深度(iPaaS/MDM)**应对大企业混乱系统群——真护城河;高调**信创全栈**;集团治理/门户。
- **治理/AI 弱点(本表最接近 ObjectStack 话术的一家)**:出**睿鲸 AI 5.0 + Dolphin AI v3**——企业 Agent 基础设施带 **MCP 连接总线 + Gateway 治理引擎(权限/限流/审计/模型路由/安全策略)**,**别说它没治理**;真缝:(a) 它治理的是 **AI Agent 运行时调用/集成**,不是**生成应用本身**从开放元数据强制的对象/记录/字段/动作权限;(b) 平台/元数据**专有封闭**、非可独立自托管的开放协议;(c) 无"人审 AI 应用改动小 diff"闭环(它的 AI 是 build-and-deliver,不是 diff-and-approve)。
- **挖角**:"得帆的 Dolphin Gateway 治理 AI agent 被允许*调用*什么——ObjectStack 治理 AI 被允许*构建*什么:每次 AI 改动落成人审小 diff,运行时从你完全拥有、可自托管的开放可读元数据强制对象/记录/字段/动作权限。同样的信创/数据主权故事,但应用核心是可审计元数据,而非另一家厂商的封闭平台。"
- **文章价值:High**——中国治理话语最直接的竞品(Gateway/审计词汇与 ObjectStack 重叠),做"agent 调用治理 vs 开放元数据应用治理"最锋利。

### ClickPaaS — 上海爱湃斯(红杉系) — High
- 模型驱动/元数据驱动企业 aPaaS(hpaPaaS),2017 创立。目标:中大型、复杂关键应用(基建/物流/政务/金融/智造/能源)。价格:销售主导、无公开。融资:种子明势,A 轮数百万美元,**2021.9 B+ 数千万美元、红杉中国领投**。"46 国/15 万企业"是自报营销、**未核实**。
- **优势**:真深的**模型驱动/元数据驱动**引擎(对标复杂企业应用)、云原生微服务、沙箱+回滚——架构上是中国最接近"元数据即应用"的一家。
- **弱点**:**AI 是软肋**——无已发布命名 AI 搭建器,只有前瞻"AI 业务助手/Agent+RAG"路线(2025),无可审 AI diff/审计/运行时治理;元数据平台内部专有、**未定位为开放可读可迁移元数据/开放协议**;私有化有,信创只是"自主可控"措辞。
- **挖角**:"ClickPaaS 已经证明元数据驱动胜过黑盒代码——但它的元数据锁在封闭平台里,AI 还停在路线图 PPT。ObjectStack 把同样的模型驱动内核做成开放、可自托管的协议:AI 写元数据、人审小 diff、运行时强制每一条权限和审计——今天就能用的可治理 AI。"
- **文章价值:High**——中国最佳架构对照(模型驱动同源让"开放+可治理 AI"对比落地)、红杉背书有认知。

### 织信 Informat — 深圳基石协作 — Medium
- 企业级低代码(OA/CRM/MES/进销存/项目),SI 式内部系统,2019。目标:中大型、制造、**军工**、金融、政府——信创/国产化。价格:免费(≤5 人)→ 专业 ~¥1/人/天 → **私有化买断(一次性永久)**;无公开 SaaS 付费档。**自举无 VC**,团队出自华为/腾讯/平安;客户含吉利、君乐宝、航空工业、中国交建。优势:**私有化优先 + 信创/麒麟 + 永久买断**,重内部系统(MES/军工)——与 ObjectStack 主权定位最直接重叠。弱点:虽喊"AI+低代码"但**无详细可治理 AI 管线**(助理式);逻辑是专有平台传统配置、非开放元数据/协议;治理=等保二级+私有化(边界治理,非对象/字段/动作 + AI 改动审计)。
- **挖角**:"织信已经卖给你私有化和信创——但它是封闭专有平台,AI 是外挂不是被治理的。ObjectStack 保持同样的私有化/国产化底座,再加织信给不了的:开放可读元数据内核,AI 写、人审 diff、运行时强制权限/审批/审计。"
- **文章价值:Medium**——主权重叠最直接,但品牌认知低、公开细节薄。

### 氚云 (Chuanyun) — 奥哲网络 — Medium/High

## 中国 AI 编程 / 应用 Agent(各 1–2 行,重叠说明)

**共同区别(楔子)**:这些都生成**不透明源代码**(或作为 IDE/CLI agent 运行)——产物是难在权限层 diff-review、运行时审计的代码。ObjectStack 生成**可治理元数据** + 可审 diff + 运行时对象/记录/字段/动作强制 + 审计。它们是给工程师的提效工具、**不是被治理的企业应用平台**,重叠**部分**。

- **字节 Trae**:"中国首个 AI 原生 IDE"(2025.3 国内版);免费、原生中文、豆包 1.5-pro + 可切 DeepSeek;Builder 模式自然语言搭整个项目。*重叠*:"描述应用→AI 搭"神似,但产物是 IDE 里裸代码库、零运行时治理。
- **通义灵码(阿里)**:AI 编码助手,**1400 万+ 下载**;公共云版改名 **Qoder CN(2026.5.20)**,加 Qwen3-Coder。*重叠*:代码补全/生成,无应用运行时权限层。
- **腾讯 CodeBuddy**:插件+IDE+CLI(2025.9 公测);四 agent(Plan/Design/Coding/Deploy)、"对话即编程"到部署;国际接 Claude/GPT/Gemini、国内用混元/DeepSeek。*重叠*:"对话→部署应用"精神最近,但交付**代码+一次部署**,非开放元数据+可审 diff+运行时强制。
- **文心快码 / Baidu Comate**:文心助手,**Comate AI IDE(2025.6)**多 agent、设计稿→代码(F2C)、支持 MCP。*重叠*:生成代码,无可治理元数据/运行时强制。
- **秘塔 Metaso**:主要是 **AI 搜索**+写作猫,**不是代码/应用搭建 agent**。与 ObjectStack 几乎无重叠。
