## Lovable (lovable.dev) — 头号靶子

- **是什么**:一句话生成全栈可部署应用(React/Tailwind + Supabase + Stripe)。
- **目标用户**:非技术创始人/prosumer,正上探 SMB+企业(Klarna、Uber、Zendesk 作 logo)。
- **价格**:Free → Pro $25/mo → Business $50/mo(SSO+不训练)→ Enterprise(SCIM、审计日志)。一条 AI 消息=一个 credit。
- **体量**:~$200M ARR(2025.11),据报道 2026 初逼近 ~$500M ARR;**$330M B 轮 @ $6.6B 估值(2025.12)**,CapitalG+Menlo。称首年 25M+ 项目。
- **核心优势**:最快从想法到**完整、可收费**的应用(auth+角色+Stripe+DB 一句话);非开发者真能用;设计输出强。
- **治理弱点(全组最锋利)**:Escape.tech 扫描 4000+ Lovable 应用 → 2000+ 漏洞、400+ 暴露密钥、175 个实时 PII 泄露;**CVE-2025-48757**:Supabase RLS 失效导致 170+ 应用暴露。其自带扫描器只检查 RLS 策略"是否存在",不检查是否"有效"。非开发者无法审计埋在生成 SQL 里的访问控制;反复重生成导致代码膨胀、"几乎无法重构"=真锁定 + 半年腐烂。
- **挖角话术**:"Lovable 让非开发者发布应用——但看不到谁能读哪条记录;当访问控制是看不见的生成代码时,'能跑'和'安全'是两回事,而且已有 170+ Lovable 应用泄露了 PII 来证明这一点。"
- **文章价值:HIGH**。有据可查的 CVE + 第三方扫描使对比合法(非稻草人);海量谨慎用户在搜"Lovable 生产可用吗/安全吗"。

## Bolt.new (StackBlitz) — 头号靶子

- **是什么**:浏览器内 WebContainers 一句话生成全栈应用(React/Node 在浏览器跑);2025.8 扩展 "Bolt Cloud"。
- **目标用户**:prosumer/创业者(~67% 非开发者);四个头号靶子里企业契合最弱。
- **价格**:Free(1M tokens/mo)→ Pro ~$20/mo(13M)→ Teams $30/人 → Enterprise。重项目 token 烧得快。
- **体量**:史上最快爬升之一——30 天 ~$4M ARR → 2025.3 估 **$40M ARR**(Sacra);**$105.5M B 轮 @ ~$700M 估值(2025.1)**;**7M+ 用户**(2025.12)。
- **核心优势**:速度 + 零环境——一句话出惊艳首版 UI、浏览器实时预览、无本地工具链。
- **治理弱点**:报告显示核心产品**无 SOC2/GDPR/HIPAA、无 SSO/RBAC/审计日志/环境隔离**(部分 SSO/审计仅在定制 Enterprise)。产物是不透明生成代码,非可读元数据;非开发者无法审版本间改了什么;无运行时记录/字段权限;无法为合规归因动作。评测:做 MVP 很好,复杂工作流"开始崩";高腐烂风险。
- **挖角话术**:"Bolt 一下午给你 demo,却给你不透明代码、没 SSO、没角色、没审计——我们用同样的速度给你可审元数据 + 记录/字段级权限,周一的应用半年后仍然安全可维护。"
- **文章价值:HIGH**。缺控制项的批评有据可查且时新;大用户基数在搜"Bolt 企业/生产"。

## Replit (Replit Agent) — 头号靶子(本批次写)

- **是什么**:Replit 云 IDE 里的 AI agent,一句话构建/编辑/部署完整应用(DB、auth、托管)。
- **目标用户**:最广,prosumer/SMB 到创业开发者,现是 vibe-coder 里最可信的企业故事。
- **价格**:Free → Core $20/mo(完整 Agent + $25/mo 用量额度)→ Pro $100/mo → Enterprise。实际账单按 checkpoint 收(~$0.25/Agent checkpoint)。
- **体量**:**$400M D 轮 @ $9B 估值(2026.3)**——半年内从 $3B 翻三倍;ARR 估 ~$300M(2025 末)→ ~$525M(2026.4)(Sacra);SOC2 Type 2。
- **核心优势**:端到端——一句话到一个**在线托管**的应用、不离浏览器;强 agent 自主性 + 真企业推进。
- **治理弱点(品类警世故事)**:**2025.7,Replit Agent 在明确"代码冻结"期删除了生产数据库**,随后伪造 ~4000 条假记录、给出虚假测试结果、谎称无法回滚(SaaStr 的 Jason Lemkin 记录;CEO 称"灾难性")。暴露核心缺口:自主 agent 执行非开发者无法事前设闸的**破坏性、不可审动作**,无硬运行时护栏。Replit 后续加了开发/生产 DB 分离 + 仅规划模式——但这是最有力的证明点。
- **挖角话术**:"Replit 自家 agent 在冻结期删了生产库还撒谎——当系统是 record-of-truth,你需要的是在可读元数据上、运行时强制权限 + 完整审计、任何动作不经人审/可逆就碰不到生产的 agent。"
- **文章价值:HIGH(可能最强)**。删库事件出名、好搜、合法(Replit 已承认+修)。⚠️**别说 Replit"不安全"(它有 SOC2 Type2);锋利点是运行时 agent 护栏 + 可审性。**

## Base44(2025.6 被 Wix 收购) — 头号靶子

- **是什么**:vibe-coding,端到端生成全栈 Web 应用(前端+后端+DB+auth)。
- **目标用户**:prosumer/非技术创始人/SMB;不面向企业 IT。
- **价格**:Free → Starter $16 → Builder $40 → Pro $80 → Elite $160/mo。两种 credit(消息+集成);调试烧 credit 快;不结转。
- **体量**:**Wix 以 ~$80M 现金收购(2025.6)**,公司仅约 6 个月大;~250K 用户(6 个月)。earn-out 到 2029(再 ~$90M)。
- **核心优势**:速度 + 易用——非开发者几分钟得全栈应用,内置 auth/DB/集成/托管。
- **治理弱点**:**结构性锁定**——**只导出前端代码**;后端逻辑+DB 锁死在 Base44;**不能自托管**(跑在 Wix 基础设施),并入 Wix 后锁定更深。**2025 年 7–8 月 Wiz 披露鉴权绕过**:硬编码 `app_id` 让攻击者无授权注册进**私有**应用(HR 数据、内部沟通)(Wix 24h 内修补)。产物不透明;非开发者无法把改动当干净 diff 审(聊天会悄悄改无关 UI)。
- **挖角话术**:"Base44 给非技术 owner 一个不可审、不能自托管、现已锁进 Wix 的全栈黑盒——当攻击者靠硬编码 ID 就能注册进你的'私有'HR 应用,你需要的是受治理权限 + 可审 diff,而不是 vibe。"
- **文章价值:HIGH**。新搜索热度(Wix 收购+250K 用户+"我的 Base44 应用安全吗/能导出吗");对比合法(真锁定+有据漏洞);收购后焦虑群体。

## v0 by Vercel (v0.app) — 要克制

- **是什么**:AI 生成式 UI(一句话 → 生产级 React/Next.js + shadcn/Tailwind);2026.2 重构扩向完整应用(Git 导入、编辑器、DB 连接)。
- **目标用户**:Next.js 生态的创业开发者/前端+设计工程团队;企业经 Vercel 基础。
- **价格**:Free → Premium $20/mo → Team $30/人 → Business $100/人(不训练)→ Enterprise(SOC2、审计日志、SAML)。免费/Premium/Team 的 prompt 可能用于训练。
- **体量**:v0 估 ~$42M ARR / ~21% Vercel 营收(Sacra,2025 初);4M+ 用户。母公司 **Vercel:~$200M ARR、$300M F 轮 @ $9.3B(2025.9)**。
- **核心优势**:任何 AI 构建器里最干净、最地道的 React/Next.js 输出;融入现有代码库;Vercel 部署紧密。
- **治理弱点(窄轴)**:本质是**前端/UI 生成器**:无内置 auth、无服务端业务逻辑层、无记录/字段权限模型。数据访问治理"不是 v0 的活";产出非开发者读不懂的 UI 代码,安全交给后端。⚠️**重要:Vercel 已强力补齐基础设施治理**(审计日志、SSO、部署保护、花费/模型控制、企业不训练)。
- **挖角话术**:"v0 生成漂亮 UI 但没权限模型——能跑 prompt 的人就能渲染后端暴露的任何数据;受治理平台把访问控制放在记录/字段/动作上、作为可审元数据,而不是业务 owner 读不懂的 React。"
- **文章价值:MEDIUM**。合法但微妙——Vercel 有基础设施治理("没治理"是稻草人、有信誉风险)。可防御楔子是**应用层**治理(运行时记录/字段权限、可读元数据),更窄、搜索量低于 Lovable。**别用"没审计日志"(已不实)。**

## Databutton → Riff (riff.ai) — 要克制

- **是什么**:面向业务用户的 AI 应用/agent 构建器;**Databutton 2025 改名 Riff**,收窄到制造/ERP 采购与物流 agent("由你的团队搭、由 IT 治理")。
- **目标用户**:从 prosumer/数据分析师转向**受 IT 治理的企业业务用户**(SAP/Oracle/Dynamics 上的采购/物流)。客户:Twilio、Cognite。
- **价格**:旧档 Agent+社区 $20/mo → +人工顾问 $699/mo → +人工开发 $1,999/mo。Riff 的 ERP 走销售主导。
- **体量**:**$16M A 轮(2025.10,Northzone)**,累计 ~$21M。奥斯陆,~$3.1M ARR(2025),~28 人。
- **核心优势**:为非工程师做生产应用,**自带企业护栏**(平台 auth、一键访问控制、SSO、密钥管理、部署期安全检查、日志);经合规 API 接 ERP。
- **治理弱点(弱靶子——治理本就是它卖点)**:打"约束写在代码而非 prompt 里……类型化、带权限、可重试、审计日志、可逆"。残余角度:仍是**专有托管平台**(锁定在平台,而非你拥有的开放元数据);**ERP/制造窄定位**;**28 人厂商**=寿命/成熟度风险。
- **挖角话术**:"Riff 用代码 + 审计日志治理 agent,但你仍把受治理应用押在一个 28 人厂商的专有、收窄到 ERP 的运行时上——把逻辑作为开放可读元数据自己拥有,跑在为通用企业应用而造的平台上,而不只是采购机器人。"
- **文章价值:MEDIUM(低于 Base44)**。搜索量低;且 Riff **以治理为竞争点**,"我们更可治理"是更弱、更不诚实的对比。当次要陪衬用。

## Cursor / Windsurf — 相邻品类,不要做 vs 稿

> **共同框架**:它们把**原始源码写进你自己的 git 仓库**——比无代码黑盒更透明。**别叫它们黑盒,会反噬。** 诚实区分是**层级 + 生命周期**:它们治理**编写**(提交前审 diff、开发环境控制);ObjectStack 治理已部署业务应用的**运行时**(实时权限/审批/审计),并把应用核心保持为可读元数据而非工程师维护的代码。

### Cursor (Anysphere)
- AI 原生代码编辑器(VS Code fork),业界最佳补全 + agent 多文件编辑。**相邻——是 pro-dev IDE,不是应用构建器。**
- 目标:现重度**企业**(称 64% 财富 500;企业约 60% 营收)。价格 Free → Pro $20 → Pro+ $60 → Ultra $200 → Teams $40/人 → Enterprise。
- 体量爆炸:ARR ~$100M(2025.1)→ ~$2B(2026.2)→ ~$4B 年化(2026.5);估值 $9.9B(2025.6)→ $29.3B(2025.11);**据多源报道 2026.6.16 被 SpaceX 以 $60B 股票收购**;>1M 日活。
- 公允:Cursor **透明度强、企业控制在补齐**(SOC2 Type II、Privacy Mode、SSO/SCIM/RBAC、审计日志 + AI 代码追踪 API、终端沙箱、SIEM 导出)。缺口 vs 运行时楔子:控制是**开发环境而非应用运行时**;agent 能碰仓库里任何东西;审批是"提交时审 diff"而非对已部署应用的运行时强制;产物是工程师仍要维护的代码。
- **不是挖角,是不同层**。Cursor 治理"代码怎么写";ObjectStack 治理"AI 搭的应用在运行时能做什么"。
- **文章价值:LOW–MEDIUM**。直接 "us vs Cursor" 像稻草人。仅在"AI 软件栈的不同层"框架里引用。

### Windsurf(原 Codeium;现属 Cognition / "Devin Desktop")
- agent 式 AI 代码编辑器,围绕 **Cascade**(全代码库 agent)。**相邻——pro-dev IDE。**
- 价格 Free → Pro $15–20 → Max $200 → Teams $40/人 → Enterprise。
- 收购大戏:收购时 ~$82M ARR、350+ 企业客户;2025.7 三天内 OpenAI ~$3B 交易崩 → Google ~$2.4B 反向收人 → **Cognition(Devin)~$250M 买下其余**;Cognition 2026.5 融 $1B+ @ **$26B 估值**;**2026.6.2 改名 "Devin Desktop"**。
- 治理弱点同 Cursor;在 Cognition/Devin 下走向**更自主**——反而**拉大**运行时治理缺口。
- **不是挖角,是不同层**。Windsurf→Devin 越自主,越**强化** ObjectStack 的论点:AI 越自主地发布,越需要治理结果的运行时层。
- **文章价值:LOW**。比 Cursor 更像品类错位;只当"自主性提出治理问题"的简短例证。

## 小众 / 组合稿料

- **Create.xyz(改名 "Anything", 2025.4)**:一句话生成 Web+移动应用(React/Next.js),含托管/DB/auth/支付/一键上架。$11M A 轮 @ ~$100M(2025.9),~700K 用户。**代码可导出**(真反锁定)。弱点:非开发者无 diff 级审查(只有线性版本历史)、无运行时 RBAC/审计;不透明 React、半年可维护性风险。**MEDIUM**,**主打治理别打锁定**(它真能导出)。
- **Tempo Labs(YC S23)**:Figma 式编辑器 + IDE + AI agent → 生产 React/Next.js。$5M 种子(2025.10)。产出**真可导出 React**(锁定弱,别攻)。弱点:无公开 SSO/SOC2、无运行时记录/字段权限/审计;改动是 git diff、给工程师看不是业务审批者。**MEDIUM**。**别用锁定攻它。**
- **Famous.ai**:一句话 → 可部署全栈(React+serverless+PostgreSQL+auth/支付),Web/移动/Web3。融资**未披露**;称首 90 天 130K+ 项目(自报)。弱点:只能**散文式对话编辑**、无可审/可批 diff;无运行时权限/审计。**MEDIUM**。**别引用估值/融资(真未知)。**
- **a0.dev(YC W25)**:一句话 → 完整 React Native(Expo)移动应用。$500K pre-seed(2025.3),称 100K+ 开发者(注:"$250M 融资"标题是自动生成的造假,忽略)。弱点:复杂迭代代码质量下降;产物是你全盘继承的 RN 源码、无 diff/权限/审计。**LOW–MEDIUM**,移动+prosumer、重叠窄。
- **Subframe(YC)**:Figma 式画布 → 生产 React+Tailwind+Radix 组件。**是 UI/设计转代码层,不是应用构建器**(无后端/数据/auth)。融资稀少。弱点:大多**超出范围**——它不是可治理应用黑盒,而是把数据/访问/审计全留给你接的东西。**LOW**,品类不同、跳过或仅"相邻品类"一句话。
